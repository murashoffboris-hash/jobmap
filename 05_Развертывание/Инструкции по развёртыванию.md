# Инструкции по развёртыванию JobMap

## Требования

### Системные требования
- **OS:** Ubuntu 24.04 LTS
- **Docker:** 29.6.2+
- **Docker Compose:** 5.3.1+
- **RAM:** минимум 4GB
- **Disk:** минимум 20GB

### Сетевые требования
- Открытые порты: 80 (HTTP), 443 (HTTPS)
- Доступ к интернету для загрузки образов
- DNS настроен на домен (если используется)

## Подготовка VPS

### 1. Подключение к VPS
```bash
ssh root@104.237.11.110
```

### 2. Обновление системы
```bash
apt update && apt upgrade -y
```

### 3. Установка Docker
```bash
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
```

### 4. Установка Docker Compose
```bash
apt install docker-compose-plugin -y
```

### 5. Проверка установки
```bash
docker --version
docker compose version
```

## Развёртывание приложения

### 1. Клонирование репозитория
```bash
cd /opt
git clone <repository-url> jobmap
cd jobmap
```

### 2. Настройка переменных окружения
```bash
cp .env.example .env
nano .env
```

Необходимые переменные:
```env
# PostgreSQL
POSTGRES_USER=job_service
POSTGRES_PASSWORD=JobMapPg2026Secure
POSTGRES_DB=job_service
POSTGRES_HOST=postgres
POSTGRES_PORT=5432

# Redis
REDIS_URL=redis://redis:6379/0

# MinIO
S3_ACCESS_KEY=minioadmin
S3_SECRET_KEY=minioadmin
S3_ENDPOINT=http://minio:9000

# Geo services
GEO_SERVICE_URL=http://192.168.1.179:8000
GEO_API_KEY=geo-api-key-local-2026

# JWT
JWT_SECRET_KEY=<generate-random-secret>
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=30

# Application
APP_ENV=production
APP_DEBUG=false
```

### 3. Сборка образов
```bash
docker compose build
```

### 4. Запуск сервисов
```bash
docker compose up -d
```

### 5. Проверка статуса
```bash
docker compose ps
```

Ожидаемый вывод:
```
NAME                STATUS
jobmap-backend      Up (healthy)
jobmap-frontend     Up (healthy)
jobmap-nginx        Up (healthy)
jobmap-redis        Up (healthy)
jobmap-worker       Up (healthy)
jobmap-minio        Up (healthy)
```

### 6. Проверка здоровья
```bash
curl http://localhost:8001/health
```

Ожидаемый ответ:
```json
{"status": "healthy"}
```

### 1. Применение миграций


## Настройка гео-сервисов

Гео-сервисы (Nominatim + OSRM) работают на отдельном сервере 192.168.1.179.

### 1. Проверка доступности
```bash

curl -H "X-API-Key: geo-api-key-local-2026" \
```

## Backup

### PostgreSQL
```bash
# Создание backup
docker compose exec postgres pg_dump -U job_service job_service > backup_$(date +%Y%m%d).sql

# Восстановление
cat backup_20260724.sql | docker compose exec -T postgres psql -U job_service job_service
```

### MinIO
```bash
# Создание backup
docker compose exec minio mc mirror local/ /backups/minio/

# Восстановление
docker compose exec minio mc mirror /backups/minio/ local/
```

## Troubleshooting

### Backend не запускается
```bash
# Проверка логов
docker compose logs backend

# Проверка зависимостей
docker compose exec backend pip list

# Перезапуск
docker compose restart backend
```

### Database connection error
```bash
# Проверка PostgreSQL
docker compose exec postgres pg_isready

# Проверка connection string
docker compose exec backend env | grep DATABASE_URL

# Перезапуск PostgreSQL
docker compose restart postgres
```

### Frontend не доступен
```bash
# Проверка Nginx
docker compose logs nginx

# Проверка frontend
docker compose logs frontend

# Перезапуск
docker compose restart frontend nginx
```

### Карта не загружается
```bash
# Проверка гео-сервисов
curl http://192.168.1.179:8000/health

# Проверка API ключа
docker compose exec backend env | grep GEO_API_KEY

# Проверка CORS
docker compose logs backend | grep CORS
```
