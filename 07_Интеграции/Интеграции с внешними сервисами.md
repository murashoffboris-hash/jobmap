# Интеграции с внешними сервисами

## Гео-сервисы

### Nominatim (Geocoding)
**Назначение:** Преобразование адресов в координаты и наоборот  
**URL:** http://192.168.1.179:8000/geocode  
**Метод:** GET  
**Параметры:**
- `address` - адрес для геокодирования
- `X-API-Key` - API ключ в заголовке

**Пример запроса:**
```bash
curl -H "X-API-Key: geo-api-key-local-2026" \
  "http://192.168.1.179:8000/geocode?address=Minsk"
```

**Пример ответа:**
```json
{
  "lat": 53.9045,
  "lon": 27.5615,
  "display_name": "Minsk, Belarus"
}
```

### OSRM (Routing)
**Назначение:** Построение маршрутов между точками  
**URL:** http://192.168.1.179:8000/route  
**Метод:** GET  
**Параметры:**
- `start` - начальные координаты (lat,lon)
- `end` - конечные координаты (lat,lon)
- `X-API-Key` - API ключ в заголовке

**Пример запроса:**
```bash
curl -H "X-API-Key: geo-api-key-local-2026" \
  "http://192.168.1.179:8000/route?start=53.9045,27.5615&end=54.6875,25.2764"
```

**Пример ответа:**
```json
{
  "distance": 340.5,
  "duration": 14400,
  "geometry": "encoded_polyline_string"
}
```

## MinIO (S3 Storage)

**Назначение:** Хранение файлов (аватары, документы)  
**Endpoint:** http://localhost:9000  
**Console:** http://localhost:9001  
**Access Key:** minioadmin  
**Secret Key:** minioadmin  

### Использование через boto3
```python
import boto3

s3 = boto3.client(
    's3',
    endpoint_url='http://minio:9000',
    aws_access_key_id='minioadmin',
    aws_secret_access_key='minioadmin'
)

# Загрузка файла
s3.upload_file('local_file.txt', 'bucket-name', 'remote_file.txt')

# Скачивание файла
s3.download_file('bucket-name', 'remote_file.txt', 'local_file.txt')
```
