# Известные проблемы JobMap

## Открытые проблемы

### BUG-001: Remote origin не настроен
**Приоритет:** HIGH  
**Статус:** Open  
**Создано:** 2026-07-24  
**Ответственный:** hr-integration-devops

**Описание:**
Git репозиторий не имеет настроенного remote origin. Это блокирует push/pull операции и CI/CD.

**Влияние:**
- Невозможно push в удалённый репозиторий
- Невозможно настроить CI/CD
- Невозможно коллаборировать с другими разработчиками

**Workaround:**
Настроить remote origin вручную:
```bash
git remote add origin <repository-url>
```

**План устранения:**
1. Создать репозиторий на GitHub/GitLab
2. Настроить remote origin
3. Настроить SSH keys или tokens
4. Протестировать push/pull

### BUG-002: Ветка develop не создана
**Приоритет:** MEDIUM  
**Статус:** Open  
**Создано:** 2026-07-24  
**Ответственный:** hr-integration-devops

**Описание:**
Отсутствует ветка develop для интеграционной разработки.

**Влияние:**
- Все изменения идут напрямую в feature-ветки
- Нет стабильной интеграционной ветки

**Workaround:**
Использовать main как интеграционную ветку.

**План устранения:**
1. Создать ветку develop от main
2. Настроить branch protection rules
3. Обновить документацию

---

### BUG-003: Worktree не настроен
**Приоритет:** MEDIUM  
**Статус:** Open  
**Создано:** 2026-07-24  
**Ответственный:** hr-integration-devops

**Описание:**
Git worktree не настроен для профилей. Все профили работают в одной рабочей директории.

**Влияние:**
- Профили могут конфликтовать друг с другом
- Невозможна параллельная разработка

**Workaround:**
Профили работают в разных ветках, но в одной директории.

**План устранения:**
1. Создать директорию worktrees/
2. Настроить worktree для каждого профиля
3. Обновить документацию

---

### BUG-005: Код фильтров поиска утерян
**Приоритет:** HIGH  
**Статус:** Open  
**Создано:** 2026-07-29  
**Ответственный:** hr-frontend-programmer

**Описание:**
При конфликте слияния задач t_fa6a80d3 → t_333991b0 код фильтров поиска вакансий был утерян.

**Влияние:**
- Фильтры поиска вакансий не работают
- Пользователи не могут фильтровать вакансии по категориям/зарплате/городу

**Workaround:**
Использовать только поиск по карте без фильтров.

**План устранения:**
1. Фронтенд-разработчик переписывает компонент фильтров (в процессе)
2. Проверить интеграцию с API поиска
3. QA-тестирование фильтров

### BUG-006: CI/CD не деплоит автоматически
**Приоритет:** HIGH  
**Статус:** Open  
**Создано:** 2026-07-29  
**Ответственный:** hr-integration-devops

**Описание:**
GitHub Actions настроен и Secrets добавлены, но автоматический деплой на VPS не срабатывает. Требуется настройка webhook-триггера или ручной запуск.

**Влияние:**
- Изменения в main не попадают на продакшен автоматически
- Требуется ручной деплой через SSH

**Workaround:**
Ручной деплой через SSH на VPS:
```bash
ssh root@104.237.11.110
cd /opt/jobmap && git pull && docker compose up -d --build
```

**План устранения:**
1. Настроить GitHub Actions webhook на push в main
2. Проверить секреты (SSH_HOST, SSH_USER, SSH_KEY)
3. Протестировать автоматический деплой
4. Обновить документацию в [[05_Развертывание/Инструкции по развёртыванию]]

### BUG-004: Модели профилей не уточнены
**Приоритет:** LOW  
**Статус:** Open  
**Создано:** 2026-07-24  
**Ответственный:** hr-orchestrator

**Описание:**
Все новые профили используют deepseek-pro по умолчанию. Необходимо уточнить модели для специализированных ролей.

**Влияние:**
- Неоптимальное использование моделей
- Возможны проблемы с качеством для некоторых задач

**Workaround:**
Использовать текущие модели до уточнения.

**План устранения:**
1. Проанализировать задачи для каждой роли
2. Выбрать оптимальные модели
3. Обновить конфигурацию профилей
