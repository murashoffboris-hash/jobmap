# Стратегия тестирования JobMap

## Уровни тестирования

### 1. Unit-тесты
**Ответственный:** hr-qa-engineer  
**Покрытие:** минимум 80% для новой функциональности  
**Инструменты:**
- Backend: pytest + pytest-asyncio
- Frontend: Vitest + React Testing Library

### 2. Integration-тесты
**Ответственный:** hr-qa-engineer  
**Покрытие:** основные интеграции между компонентами  
**Инструменты:**
- Backend: pytest + httpx
- Frontend: Vitest + MSW (Mock Service Worker)

### 3. End-to-End тесты
**Ответственный:** hr-qa-engineer  
**Покрытие:** критические пользовательские сценарии  
**Инструменты:**
- Playwright или Cypress

### 4. Ручное тестирование
**Ответственный:** hr-qa-engineer  
**Покрытие:** UI/UX, доступность, кроссбраузерность

### Пример unit-теста
```python
import pytest
from httpx import AsyncClient
from app.main import app

@pytest.mark.asyncio
async def test_create_vacancy():
    async with AsyncClient(app=app, base_url="http://test") as ac:
        response = await ac.post(
            "/api/vacancies",
            json={
                "title": "Python Developer",
                "description": "FastAPI developer needed",
                "location": "Minsk",
                "salary": 3000
            }
        )
    assert response.status_code == 201
    assert response.json()["title"] == "Python Developer"
```

### Запуск тестов
```bash
cd backend
pytest
pytest --cov=app --cov-report=html
pytest -v -s
```

```typescript
import { render, screen } from '@testing-library/react'
import { Button } from './Button'

describe('Button', () => {
  it('renders correctly', () => {
    render(<Button>Click me</Button>)
    expect(screen.getByText('Click me')).toBeInTheDocument()
  })
  
  it('calls onClick when clicked', async () => {
    const handleClick = vi.fn()
    render(<Button onClick={handleClick}>Click me</Button>)
    await screen.getByText('Click me').click()
    expect(handleClick).toHaveBeenCalledTimes(1)
  })
})
```

## E2E тестирование

### Критические сценарии
1. Регистрация пользователя
2. Вход в систему
3. Создание вакансии
4. Поиск вакансий на карте
5. Редактирование профиля

### Пример E2E теста (Playwright)
```typescript
import { test, expect } from '@playwright/test'

test.describe('Authentication', () => {
  test('user can register', async ({ page }) => {
    await page.goto('/register')
    await page.fill('input[name=email]', 'test@example.com')
    await page.fill('input[name=password]', 'password123')
    await page.click('button[type=submit]')
    await expect(page).toHaveURL('/dashboard')
  })
  
  test('user can login', async ({ page }) => {
    await page.goto('/login')
    await page.fill('input[name=email]', 'test@example.com')
    await page.fill('input[name=password]', 'password123')
    await page.click('button[type=submit]')
    await expect(page).toHaveURL('/dashboard')
  })
})
```

## Непрерывная интеграция

### GitHub Actions
```yaml
name: Test

on: [push, pull_request]

jobs:
  backend-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Run backend tests
        run: |
          cd backend
          pytest --cov=app --cov-report=xml
          
  frontend-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Run frontend tests
        run: |
          cd frontend
          npm test -- --coverage
```
