# Архитектура системы JobMap

## Обзор

JobMap — кроссплатформенный сервис поиска работы с микросервисной архитектурой, разделённый на backend, frontend и инфраструктурные компоненты.

## Компоненты системы

### Backend (FastAPI)
- **Порт:** 8001
- **Фреймворк:** FastAPI (async)
- **ORM:** SQLAlchemy 2.0+ с asyncpg
- **База данных:** PostgreSQL 16 + PostGIS 3.4
- **Кэш:** Redis 7
- **Очереди:** Celery
- **Файловое хранилище:** MinIO (S3)
- **Миграции:** Alembic

### Frontend (React)
- **Фреймворк:** React 18
- **Язык:** TypeScript 5
- **Bundler:** Vite 5
- **Мобильное приложение:** Capacitor 6
- **Карты:** MapLibre 4
- **PWA:** Да

### Инфраструктура
- **Web-сервер:** Nginx (reverse proxy)
- **Контейнеризация:** Docker Compose
- **VPS:** 104.237.11.110 (Ubuntu 24.04)
- **Гео-сервисы:** Nominatim + OSRM (192.168.1.179)

## Поток данных

### Авторизация
1. Frontend → Backend: POST /api/auth/login
2. Backend → PostgreSQL: Проверка credentials
3. Backend → Frontend: JWT token
4. Frontend: Хранение token в localStorage
5. Frontend → Backend: Bearer token в headers

### Поиск вакансий
1. Frontend → Backend: GET /api/vacancies?lat=X&lon=Y&radius=Z
2. Backend → PostgreSQL+PostGIS: Spatial query
3. Backend → Frontend: Список вакансий с координатами
4. Frontend → MapLibre: Отображение маркеров на карте

### Геокодирование
1. Frontend → Backend: GET /api/geocode?address=...
2. Backend → Гео-сервер: HTTP request
3. Гео-сервер → Nominatim: Geocoding
4. Backend → Frontend: Координаты

## Масштабирование

### Горизонтальное масштабирование
- Backend: Несколько инстансов за Nginx load balancer
- PostgreSQL: Read replicas
- Redis: Redis Cluster
- Celery: Несколько workers

### Вертикальное масштабирование
- Увеличение ресурсов VPS
- Оптимизация запросов к БД
- Кэширование часто запрашиваемых данных

## Безопасность

### Аутентификация
- JWT tokens
- Refresh tokens
- Rate limiting на login endpoints

### Авторизация
- Role-based access control (RBAC)
- Проверка прав на каждый endpoint

### Защита данных
- HTTPS только
- Шифрование паролей (bcrypt)
- Защита от SQL injection (parameterized queries)
- Защита от XSS (input sanitization)
- CORS policy

## Мониторинг

### Health checks
- Backend: /health endpoint
- PostgreSQL: pg_isready
- Redis: redis-cli ping
- MinIO: mc ready

### Логирование
- Docker logs
- Application logs
- Nginx access/error logs

## Backup

### PostgreSQL
- Daily pg_dump
- Хранение 7 дней
- Автоматическое восстановление

### MinIO
- mc mirror для синхронизации
- Хранение на отдельном volume
