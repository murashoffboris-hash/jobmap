# ADR-001: Выбор технологического стека

**Статус:** Принято  
**Дата:** 2026-07-22  
**Контекст:** Необходимо выбрать стек для кроссплатформенного сервиса поиска работы (JobMap).

## Решение

### Backend
- **FastAPI** — асинхронный Python-фреймворк, высокая производительность, автодокументация OpenAPI
- **SQLAlchemy 2.0** + **asyncpg** — ORM + асинхронный драйвер PostgreSQL
- **PostgreSQL 16 + PostGIS 3.4** — реляционная БД + геопространственные расширения
- **Redis 7** — кэш + брокер Celery
- **Celery** — фоновые задачи (уведомления, обработка загрузок)
- **MinIO** — S3-совместимое файловое хранилище (резюме, аватарки)

### Frontend
- **React 18 + TypeScript 5 (strict)** — основа UI
- **Vite 5** — сборщик (быстрая dev-среда)
- **Capacitor 6** — нативная обёртка для iOS/Android
- **MapLibre 4** — карты (OpenStreetMap, без платных API)
- **Tailwind CSS 3.4** — утилитарный CSS
- **Zustand** — лёгкий state management
- **Axios** — HTTP-клиент

### Инфраструктура
- **Docker Compose** — оркестрация контейнеров
- **Nginx** — reverse proxy + HTTPS
- **Let's Encrypt** — SSL-сертификаты
- **VPS 104.237.11.110** — хостинг

## Последствия
- Единый язык (Python) для всего backend — снижает сложность поддержки
- PostGIS даёт полноценный геопоиск без внешних платных API
- Capacitor позволяет собрать мобильное приложение без переписывания фронта
- Tailwind — меньше CSS-кода, дизайн-система в конфиге
- Docker Compose упрощает деплой, но требует ручной настройки SSL
