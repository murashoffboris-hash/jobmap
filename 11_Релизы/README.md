## Структура папки

Каждый релиз документируется отдельным файлом с префиксом цикла:
- `MVP-cycle-N.md` — итоговый отчёт по циклу разработки
- `release-vX.Y.Z.md` — production-релиз (после HTTPS + CI/CD)

## Формат отчёта

5. Связанные документы
