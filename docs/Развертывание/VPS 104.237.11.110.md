## Self-hosted Geo-сервисы

С 2026-07-26 все гео-сервисы переведены на self-hosted (VPS 104.237.11.110).
Публичные сервисы (nominatim.openstreetmap.org, router.project-osrm.org, CartoDB)
больше не используются напрямую — только как fallback.

### OSRM (маршруты)

| Параметр | Значение |
|----------|----------|
| Контейнер | `jobmap-osrm` |
| Порт (внутренний) | 5000 |
| Docker-сеть | `jobmap_jobmap-net` (alias: `osrm`) |
| Backend URL | `OSRM_URL=http://osrm:5000` |
| Fallback URL | `OSRM_FALLBACK_URL=https://router.project-osrm.org` |
| Данные | `/opt/geo/belarus.osrm*` (346 MB PBF → preprocessed) |

| Обновление | Разово. При необходимости: скачать свежий belarus.osm.pbf с geofabrik.de → `docker compose up osrm -d` |

### Nominatim (геокодинг)

| Параметр | Значение |
|----------|----------|
| Контейнер | `jobmap-nominatim` |
| Порт (внутренний) | 8080 |
| Docker-сеть | `jobmap_jobmap-net` (alias: `nominatim`) |
| Backend URL | `NOMINATIM_URL=http://nominatim:8080` |
| Fallback URL | `NOMINATIM_FALLBACK_URL=https://nominatim.openstreetmap.org` |
| Образ | `mediagis/nominatim:4.5` |
| Данные | `/opt/geo/belarus.osm.pbf` (331 MB) → PostgreSQL (`/opt/geo/nominatim-data`) |
| Обновление | Ежемесячно: скачать свежий belarus.osm.pbf с [geofabrik.de/belarus](https://download.geofabrik.de/europe/belarus.html) → перезапустить контейнер |

> ⚠️ **Критически важно:** Контейнер Nominatim **всегда делает `DROP DATABASE` и полный реимпорт** при запуске
> (см. `/app/init.sh`). Занимает ~25 минут для Belarus. **Никогда не перезапускайте контейнер без необходимости.**
> Для штатной работы после импорта контейнер должен работать непрерывно.
> 
> Для предотвращения краша при старте обязательно: `FREEZE=true` (пропускает replication init).

#### Обновление данных Nominatim (monthly)

```bash
# 1. Скачать свежий PBF
cd /opt/geo
wget -O belarus.osm.pbf https://download.geofabrik.de/europe/belarus-latest.osm.pbf

# 2. Удалить старый volume и контейнер
docker rm -f jobmap-nominatim
docker volume rm nominatim-pgdata

# 3. Запустить реимпорт (~20 мин для Belarus)
docker volume create nominatim-pgdata
docker run -d --name jobmap-nominatim \
  --network jobmap_jobmap-net --network-alias nominatim \
  -p 127.0.0.1:8080:8080 \
  -v /opt/geo/belarus.osm.pbf:/opt/geo/belarus.osm.pbf:ro \
  -v nominatim-pgdata:/var/lib/postgresql/16/main \
  -v /opt/geo/nominatim-flatnode.file:/nominatim/flatnode.file \
  -e PBF_PATH=/opt/geo/belarus.osm.pbf \
  -e REPLICATION_URL=none \
  mediagis/nominatim:4.5

# 4. Ждать readiness: curl http://localhost:8080/ → 200
```

### Tileserver (карта)

| Параметр | Значение |
|----------|----------|
| Контейнер | `jobmap-tileserver` |
| Порт (внутренний) | 8080 |
| Docker-сеть | `jobmap_jobmap-net` |
| Nginx proxy | `/tiles/` → `tileserver:8080` |
| Образ | `maptiler/tileserver-gl` |
| Данные | `/opt/geo/belarus.mbtiles` (403 MB, tilemaker) |
| Стиль | basic-preview, URL: `/tiles/style.json` |
| Nginx URL rewrite | `sub_filter` заменяет `http://tileserver:8080/` → `/tiles/` в style.json |
| Обновление | Разово. При необходимости: перегенерировать mbtiles через tilemaker из свежего PBF |

> ⚠️ **Важно:** Tileserver-GL генерирует style.json с абсолютными URL `http://tileserver:8080/`.
> Nginx выполняет `sub_filter` для перезаписи на same-origin `/tiles/`. При обновлении конфигурации
> tileserver убедиться, что sub_filter покрывает все URL (data, fonts, glyphs).

#### Проверка карты

```bash
# Style JSON
curl https://jobmap.by/tiles/style.json
# TileJSON
curl https://jobmap.by/tiles/data/v3.json  
# Конкретный тайл (Минск, z=7)
curl -I https://jobmap.by/tiles/data/v3/7/76/39.pbf
```
