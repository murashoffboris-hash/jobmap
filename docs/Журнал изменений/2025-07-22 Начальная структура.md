- `frontend/dist/.gitkeep` — placeholder для Flutter-сборки
- `.env.example` — все переменные окружения
- `.gitignore` — секреты, ключи, бинарные файлы

## Переменные окружения

Все в `.env.example`. PostgreSQL, Nominatim, OSRM — на VPS, подключение через `.env`.

## Миграции базы данных

Alembic настроен, `env.py` импортирует все модели включая GeoAlchemy2. Миграции создаются командой:
```bash
alembic -c migrations/alembic.ini revision --autogenerate -m "описание"
alembic -c migrations/alembic.ini upgrade head
```
